02

Where AI Worked, Where It Didn't, and Where I Overrode It

Worked Well

  • Schema + 28 routes correct on first pass — transactions, idempotency, FK constraints
  • 16 parallel page builds — no merge conflicts, consistent patterns
  • Security audit found 17 real bugs: missing auth, state machine gaps, race conditions
  • Complex UI — glassmorphism, SVG charts, QR scanner, certificates from mockups

Needed Correction

  • Prisma 7 auto-installed → downgraded to v5 (AI fluency > latest)
  • Auth redirect loop → restructured route groups
  • .env key conflict → placeholders overwrote real keys
  • Stale pages → added force-dynamic to 9 pages
  • Turbopack crash → switched to build+start workflow
  • Capacity "45/100" → "Seats Available" only (my domain call)
